### Home Screen Widgets, Siri & Shortcuts
Add small or medium WLED widgets to your Home Screen to check status and Wi-Fi signal strength, toggle power, or jump straight to a device, and control your lights from Siri, the Shortcuts app, or the Action button — including setting brightness from 0% to 100%.

### Custom Firmware Updates
Added OTA update support for **QuinLED** and **MoonModules** boards alongside official WLED releases.

### Smoother Connections & Discovery
Faster automatic device discovery, more reliable real-time status updates, and a 60-second offline grace period so lights don't flicker into the offline list during brief reconnects. Prefer a quieter network? You can also turn off automatic background discovery in Settings.

### What's New Changelog
Automatically see release notes after an app update or revisit them anytime from Settings (just like the one you are reading right now!).

### Other Improvements
- Added German and Simplified Chinese translations.
- Added Light, Dark, and System Default theme selection in Settings.
- Added a "Show Offline Devices Last" setting to either group offline devices at the bottom or sort them alphabetically with online devices.
- Added a battery level indicator for devices with the battery usermod enabled.
- Added an Edit swipe action and a confirmation prompt before deleting devices from the list.
- Added the firmware update source repository and offline update status to the Edit Device screen.
- Added a live download progress bar when installing firmware updates and a loading bar while connecting to a device.
- Added a cleaner offline screen with a Retry Connection button when a device cannot be reached.
